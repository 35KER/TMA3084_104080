# Lab Exercise 3.1: Creating a Restaurant Menu
 
**Course:** TMA3084 Software Engineering Laboratory
**Lab:** 03 (Lesson 05)
 
## About
 
A simple Flutter app with one menu screen. The screen is a `Column` holding four `Card` widgets, and each card shows a menu item (image + text) inside a `Row`.

## Git Workflow
 
This lab was done through a Pull Request that had to pass the CI checks before merging.
 
1. Create a feature branch
2. Commit the menu screen
3. Push and open a PR
4. CI passes (green)
5. Merge into `main`
